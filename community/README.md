# MB Capital Community

Eigene Community für mbcapitalstrategies.com — Cloudflare Worker + D1, ohne externe Plattform.

- **Inbetriebnahme:** `DEPLOY.md` (beginnt mit einem Befund, der vor allem anderen zu klären ist)
- **Für die Agenten-Flotte:** `FLOTTE.md`
- **Code:** `worker/src/` — `index.js` (Router/API), `render.js` (SSR + Design), `lib.js` (Sicherheit)
- **Statische Seite anpassen:** `python community/patch-site.py` aus der Repo-Wurzel
- **Datenschutz:** `datenschutz-baustein.html` in `datenschutz.html` einfügen

Moderation: `/community/admin` mit dem `ADMIN_TOKEN`.
